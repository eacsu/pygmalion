## 先设计，后代码

已在共享组件 `192:1357` 中复用原有按钮实例，添加“笔头定位”（`295:941`）和“默认字号”（`295:943`）。共享实例继承这些入口，保持 Noto Sans SC、语义配色、32px 按钮、4px 圆角及纵向自动布局。主画板核验包含可编辑文本、组件及矢量图层，没有整页栅格图。

代码同步新版的顶栏菜单、112px 工具栏、中央纸面和 304px 属性区。插入、编辑和视图通过留白分组；坐标在左下，预览与校核在右下。空闲时收起全局任务条，有任务或错误时保留反馈。默认字号入口展开现有设置并聚焦输入，不改变字号保存逻辑。保留 SVG、表格、笔头定位、撤销重做、自动保存、执行模式与机器控制能力。

1000px 及以下保留适合触屏的横向工具栏与按需属性面板。属性关闭时校核反馈仍留在纸面下方。

## 视图与文档新版

当前同步依据 [03 · 书写 · 视图与文档](https://www.figma.com/design/m1toyRcCag4OOsJNMebFDb?node-id=290-46652)，包括 `203:27385` 导航展开、`203:26878` 属性收起等状态。顶栏为 128px 应用位置及 392px 文档区；菜单为 200px 就地浮层，不挤压画布。保留重命名、保存失败重试、属性独立滚动及 150% 平移能力。属性数值改用透明底和轻量边界，hover、focus 和错误仍有明确反馈。

纸张现为纯参考背景：取消页边距虚线与边框限制，真实预览覆盖纸外内容；自由坐标、笔头定位和尺寸保存后仍保持毫米语义。此行为按用户明确要求覆盖旧设计中的纸张边界约束。

## 开始与停止动作同步

Figma 的 `Console/StartAction`（`218:1406`）保留原有 Blocked / Ready，并新增 Running（`328:833`，“停止书写”）与 Stopping（`328:836`，“正在停止”）。复用原有主按钮、禁用按钮、Noto Sans SC 和主题变量，尺寸均为 104×32px；组件页提供可编辑实例对照 `328:845`。

书写任务页 `290:46667`、设备任务页 `290:46700`、参数任务页 `290:46716` 共更新 24 张双主题画板：running / sent100 显示可停止状态，aborting / aborted-waiting 显示禁用停止中状态。机器和参数顶栏的预留位置增加默认隐藏的共享动作实例，仅活动任务画板显示；空闲和完成状态不增加停止操作。

运行态通过 Figma 跨页原型链接进入 `290:46742` 内对应页面及主题的中止确认，停止中不设置点击动作。跨页直接 OVERLAY 目标不被当前 Figma API 接受，因此沿用文件已有的跨页原型 URL 方式。已核验动作状态、字体、尺寸、链接及双主题截图；所有新增内容均为组件和可编辑文本，没有导入界面截图。


## 时间与进度、笔尖标记

`Console/TaskStatus`（`192:1418`）的 Sending / Sent / Aborting / Complete 复用原字体和主题变量加入指令发送进度条与时间样例；窄属性区实例沿用 44px 高度，进度条置于底部，避免挤压文字。主页面双主题的预览行改为预计用时示例；100% 仍显示等待设备完成。已核验共享组件继承、文字尺寸及截图。新增 `Workbench/PenAnchor`（`340:844`）使用与代码相同的笔尖 SVG，保留 32px 操作区域，不带圆圈、十字和标签。

## 电路编辑与两点测量

新增可编辑 [电路与测量双主题画板](https://www.figma.com/design/m1toyRcCag4OOsJNMebFDb?node-id=362-695)：电路编辑为 `362:696` / `362:1311`，两点测量为 `362:1926` / `362:2544`。先从现有工作台克隆，在原有结构中替换纸面内容和属性，保留顶栏、工具栏、Noto Sans SC、按钮实例和主题变量。移除常驻刻度及其占位；复用 Ghost 按钮增加“测量”，纸面墨迹绑定原有 `color/paper/ink`，避免夜间主题把纸上的文字变成浅色。

电路属性表示当前元件、编号、参数、方向和位置；测量状态表示长度及水平/垂直分量、端点操作和退出方式。纸面内容为矢量与可编辑文字，没有界面截图。已核验新增图层、按钮位置及深浅主题截图。代码沿用既有响应式工作台，窄屏工具条可横向滚动，属性按需打开。

本轮验证：后端 223 项、完整浏览器回归 70 项通过；最后的测量交互调整另通过 5 项专项检查。构建、ESLint、Ruff 与 API 类型一致性检查通过；视觉检查覆盖电路编辑和测量、深浅主题及 390px 入口。全部自动检查使用隔离目录，不连接真实串口。

电路属性双主题画板增加复用 Ghost 按钮的“自动排版”（`366:949` / `366:951`），同步整理说明；共享任务组件 Complete 状态隐藏进度图层 `335:852`，终态保留任务结果，停止确认期间仍有状态反馈。

## 笔头可见性修复

`340:844` 的笔尖图形容器 `340:845` 放大 1.5 倍，尖端仍对准组件中心，不增加圆圈；原点实例绑定工作空间文字色，修复夜间黑色笔尖落在深色纸外背景上的问题。新增双主题“笔头移出视野”画板 `369:954` / `369:1071`，复用 Ghost 按钮增加“笔头在视野外 · 显示笔头”（`369:1069` / `369:1186`）。

代码在缩放、平移、滚动及窄屏面板遮挡后提供视图找回；操作不修改文档定位、不移动机器。浏览器验证增加视口内完整显示、点击命中、夜间对比色和找回前后数据库版本不变检查。另修复输入启用时编辑锁引用的同步时机，避免首个输入事件的撤销分组因状态落后一帧而丢失。
