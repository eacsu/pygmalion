## 视图与文档新版

当前同步依据 [03 · 书写 · 视图与文档](https://www.figma.com/design/m1toyRcCag4OOsJNMebFDb?node-id=290-46652)，包括 `203:27385` 导航展开、`203:26878` 属性收起等状态。顶栏为 128px 应用位置及 392px 文档区；菜单为 200px 就地浮层，不挤压画布。保留重命名、保存失败重试、属性独立滚动及 150% 平移能力。属性数值改用透明底和轻量边界，hover、focus 和错误仍有明确反馈。

纸张现为纯参考背景：取消页边距虚线与边框限制，真实预览覆盖纸外内容；自由坐标、笔头定位和尺寸保存后仍保持毫米语义。此行为按用户明确要求覆盖旧设计中的纸张边界约束。

## 开始与停止动作同步

Figma 的 `Console/StartAction`（`218:1406`）保留原有 Blocked / Ready，并新增 Running（`328:833`，“停止书写”）与 Stopping（`328:836`，“正在停止”）。复用原有主按钮、禁用按钮、Noto Sans SC 和主题变量，尺寸均为 104×32px；组件页提供可编辑实例对照 `328:845`。

书写任务页 `290:46667`、设备任务页 `290:46700`、参数任务页 `290:46716` 共更新 24 张双主题画板：running / sent100 显示可停止状态，aborting / aborted-waiting 显示禁用停止中状态。机器和参数顶栏的预留位置增加默认隐藏的共享动作实例，仅活动任务画板显示；空闲和完成状态不增加停止操作。

运行态通过 Figma 跨页原型链接进入 `290:46742` 内对应页面及主题的中止确认，停止中不设置点击动作。跨页直接 OVERLAY 目标不被当前 Figma API 接受，因此沿用文件已有的跨页原型 URL 方式。已核验动作状态、字体、尺寸、链接及双主题截图；所有新增内容均为组件和可编辑文本，没有导入界面截图。


## 时间与进度、笔尖标记

`Console/TaskStatus`（`192:1418`）的 Sending / Sent / Aborting / Complete 复用原字体和主题变量加入指令发送进度条与时间样例；窄属性区实例沿用 44px 高度，进度条置于底部，避免挤压文字。主页面双主题的预览行改为预计用时示例；100% 仍显示等待设备完成。已核验共享组件继承、文字尺寸及截图。新增 `Workbench/PenAnchor`（`340:844`）使用与代码相同的笔尖 SVG，保留 32px 操作区域，不带圆圈、十字和标签。
